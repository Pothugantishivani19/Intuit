
# Cat Breeds App

This project was developed as part of an iOS technical assessment for Intuit.

The app displays different cat breeds along with their details such as description, temperament, life span, and images. Users can search breeds, sort the list, filter by origin, and mark breeds as favorites.


## Features

- View list of cat breeds
- Search breeds by name
- Sort breeds:
  - Name A–Z
  - Name Z–A
  - Life span: Shortest First
  - Life span: Longest First
- Mark and unmark favorites
- Show only favorite breeds
- Filter breeds by origin
- View detailed breed information with image

## Screens

### Home Screen
- Displays all cat breeds
- Search functionality
- Favorite option for each breed
- Sort and filter menu

### Detail Screen
- Breed image
- Description
- Temperament
- Life span
- Favorite option
